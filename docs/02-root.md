# 2. Root на колонке через lite-kit

Стенд подменяет ответ сервера `quasar.yandex.net`. Колонка получает настоящий ответ Яндекса с добавленным `adbd.remoteActivation` и открывает сетевой ADB с правами root. Сторонние серверы не нужны. Метод описан на [hackalice.me](https://hackalice.me/) (вариант с локальным стендом).

## 1. Прошивка

Для Мини 1 нужна сборка `1.305.4.16.3237824040.20250721`, на более новых ADB не поднимается. Установщик качает её с сервера в Германии, который из РФ может «зависать» на 32 КБ.

```bash
cd ~/lite-kit && chmod +x *.sh && ./install-firmware.sh   # yandexmini → 1.305.4.16.3237824040.20250721
```

Если загрузка застряла, скачайте файл на машине с VPN (`http://144.76.194.29:62891/yandexmini/1.305.4.16.3237824040.20250721/update.zip`, 53,4 МБ) и закиньте в контейнер:

```bash
scp ~/Downloads/update.zip root@192.168.1.49:/root/lite-kit/firmware/1.305.4.16.3237824040.20250721.zip
```

## 2. Запуск стенда

```bash
cd ~/lite-kit && ./start.sh
```

Стенд печатает свой IP и проверяет DNS. Логи — `~/lite-kit/log/server.log`.

## 3. Сброс колонки

Отключите питание, зажмите кнопку активации Алисы, подайте питание и держите 5–10 секунд до жёлтого кольца. Не сработало — то же с кнопкой микрофона.

## 4. Привязка с подменой DNS

1. В приложении «Дом с Алисой»: «+» → «Устройство с Алисой» → Мини. Дойдите до экрана пароля Wi-Fi и остановитесь.
2. В роутере: **DHCP → DNS-сервер 1 = 192.168.1.49, DNS-сервер 2 пусто**. Сохраните.
3. Нажмите «Подключиться».

> На Keenetic с xkeen команда `ip host` не работает, DNS подменяется только через DHCP. На время привязки интернет в сети может пропадать, это нормально. Держите подмену только до получения ADB и до конца [части 3](03-ota-ssh.md).

## 5. Обновление до нужной сборки

Если на колонке старая прошивка (в нашем случае 1.3.4 от 2019 года), стенд сам отдаст 1.305. Колонка скажет «обновляюсь» и перезагрузится, питание не трогайте. После этого привязку, возможно, придётся пройти второй раз.

## 6. Проверка ADB

В логе стенда должна появиться строка `[SYNC-REAL→] … adbd=on`, затем:

```bash
adb connect 192.168.1.102:5555
adb shell id     # uid=0(root)
```

Не возвращайте обычный DNS, пока не сделана [часть 3](03-ota-ssh.md).
