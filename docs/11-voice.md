# Качество голоса: Silero (рекомендуется)

Piper работает «из коробки», но звучит роботизированно. Для русского языка рекомендуем **Silero TTS**: он тоже работает локально на процессоре (видеокарта не нужна), но звучит заметно живее. Проверено на этой схеме: мост использует его как обычный движок TTS из HA.

Мост берёт любой TTS-движок HA, поэтому в самом мосте ничего менять не нужно.

## Установка

Используется сообщество-проект [Silero TTS Enhanced](https://community.home-assistant.io/t/silero-tts-enhanced-fast-local-and-flexible-text-to-speech-for-home-assistant-hacs-add-on/1011745): дополнение HA плюс интеграция через HACS.

1. **Место на диске.** Модели и образ занимают несколько гигабайт. Если установка падает с `not enough free space`, расширьте диск виртуальной машины HA (на Proxmox: Hardware → Hard Disk → Resize, +16 ГБ) и перезагрузите её.
2. **Дополнение.** **Настройки → Дополнения → Магазин → ⋮ → Репозитории**: добавьте репозиторий дополнения из описания проекта, установите и запустите дополнение. В разделе «Сеть» дополнения должен быть указан порт (по умолчанию 8014).
3. **Интеграция.** В HACS добавьте репозиторий интеграции как пользовательский, установите, перезапустите HA и добавьте интеграцию в **Устройства и службы**. В поле «URL сервера (Дополнения)» впишите адрес вашего HA с портом, например `http://192.168.1.111:8014`. Значение по умолчанию подходит не всегда.
4. В **Инструменты разработчика → Состояния** найдите новую сущность `tts.…` (в нашем случае `tts.silero_tts_enhanced`).
5. В **Настройки → Голосовые помощники** выберите её у помощника, выберите голос и нажмите «Прослушать».

## Подключение к колонке

В карточке устройства NOEMA Alice откройте список **«Движок речи»** и выберите `tts.silero_tts_enhanced`. Выбор применяется сразу ([часть 8](08-ha-integration.md)). Без патча `apply_config.py` задайте `HA_TTS=tts.silero_tts_enhanced` в `ha.env` моста и перезапустите службу `alice-ha`.

> После смены движка фразы, которые уже озвучивались, могут один раз прозвучать старым голосом из кэша. Проверяйте новой фразой.

## Что учесть

- Для разговора через `tts.speak` укажите новую сущность (`tts.silero_tts_enhanced`), а не `tts.piper`. Для ответов на «Алиса, …» и для `play_media` с `dialog` достаточно настройки моста.
- Silero звучит лучше Piper, но остаётся синтезом речи.
